# Q&A Credibility Annotation Guidelines

Use one label per Q&A pair:

## `direct`

The answer materially addresses the question asked.

Typical signs:

- explicit yes/no or clear directional answer
- quantitative detail tied to the question
- scope and time horizon are specific

## `partial`

The answer addresses only part of the question.

Typical signs:

- responds to one sub-part while skipping another
- gives high-level framing without requested precision
- provides context but no concrete commitment

## `evasive`

The answer avoids the substance of the question.

Typical signs:

- refusal to comment without meaningful substitute
- generic messaging repeated from prepared remarks
- topic pivot that does not resolve the asked point

## Adjudication Rules

1. Label the answer quality, not whether management was "right."
2. If uncertain between two labels, prefer the weaker one (`direct` -> `partial`, `partial` -> `evasive`).
3. Keep `annotator_notes` short and factual.
